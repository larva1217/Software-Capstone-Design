# 소프트웨어캡스톤디자인
최근 금융 시장에 대한 접근성이 향상되며 개인 투자자의 시장 참여가 크게 증가했습니다. 스마트폰과 모바일 환경의 발전으로 누구나 쉽게 주식 거래를 할 수 있게 되었으나, 투자 경험과 금융 지식이 부족한 상태에서 시장에 진입하여 경제적 손실을 겪는 사례 또한 빈번하게 발생하고 있습니다. 
이러한 문제를 해결하기 위해, 사용자가 실제 자금을 잃을 위험 없이 데이터를 기반으로 투자 의사결정 과정을 온전히 경험할 수 있는 모의 투자 시스템을 구현하고자 했습니다.
본 프로젝트는 실제 주식 데이터를 활용하여 사용자가 가상의 환경에서 주식 투자를 실습할 수 있는 웹 서비스 구축을 목표로 합니다. 사용자는 종목 검색 기능을 통해 주식 정보를 조회할 수 있도록 설계했으며, 주가 차트를 통해 가격 변동을 직관적으로 확인할 수 있도록 구현할 예정입니다.
또한 사용자가 가상의 자금을 이용하여 주식을 매수 및 매도할 수 있는 기능을 제공하고자 했습니다. 이를 통해 실제 투자와 유사한 환경에서 거래를 경험할 수 있도록 하고, 거래 내역을 데이터베이스에 저장하여 추후 분석이 가능하도록 구현할 계획입니다.
더불어 포트폴리오 관리 기능을 통해 사용자가 보유 자산과 수익률을 한눈에 확인할 수 있도록 설계했습니다. 각 종목의 현재 가치와 투자 성과를 계산하여 제공함으로써, 사용자가 자신의 투자 전략을 분석하고 개선할 수 있도록 하는 것을 목표로 했습니다.
본 프로젝트를 수행하는 과정에서 웹 애플리케이션 개발에 필요한 다양한 기술을 학습하고자 했습니다. HTML과 CSS를 활용하여 사용자 인터페이스를 구성하고, Java Spring을 기반으로 서버 로직을 구현하며, MySQL 데이터베이스를 활용하여 데이터를 관리할 계획입니다. 또한 외부 API를 연동하여 주식 데이터를 수집하고 이를 시각화하는 기능을 구현하고자 했습니다. 이를 통해 웹 서비스의 전체적인 구조를 이해하고 실무에 가까운 개발 경험을 쌓는 것을 목표로 했습니다.
